🎯 Project Overview

This assignment evaluates two major skills:

Task 1 — Webpage Creation

Convert a given UI (Figma design) into clean HTML & CSS.

Use semantic HTML5 and responsive CSS.

Produce a professional, visually aligned layout.

Task 2 — Dynamic Page

You are given JSON-like data and expected to implement:

Add notes

Prevent duplicate notes

Limit to 3 notes per thread

Simple delete + edit functionality

Basic search & sorting

All logic is implemented with simple JavaScript—no frameworks.

🚀 Features Implemented
✅ UI & Layout

Fully responsive layout

Sidebar + main content

Card-style containers

Dark theme visual aesthetic

✅ Dynamic Note System (Vanilla JS)

Add notes

Edit notes

Delete notes

Prevent duplicates

Limit to 3 unique notes

Show count of notes

Load sample JSON data

Reset thread

Search notes

Sort by newest or oldest
